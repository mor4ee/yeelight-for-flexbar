# Yeelight for Flexbar 0.1.0

Control compatible Yeelight lights over your LAN from five independent
Flexbar controls: On/Off, Brightness, Color Temperature, Hue and Saturation.
Each control can target a different light. Supported background lights appear
as separate targets. Set a brightness range without shortening the slider.

## Downloads and setup

- **com.mor4ee.yeelight.flexplugin** — import into FlexDesigner on Windows,
  enable LAN Control on the light, then scan from the plugin settings. Yeelight
  Station is optional; no cloud account is required for runtime control.
- **Yeelight Vector Icon Pack.iconpack** — 15 fixtures, 30 white On/Off icons.
- **Yeelight Color Icon Pack.iconpack** — 14 fixtures, 70 transparent icons
  with unlit and four illuminated variants.

Import either optional pack through Foreground → Icon pack → Import. Assign
Off and On separately. Colors in the imported artwork are fixed.

The verified development baseline is FlexDesigner 2.2.3 on Windows. The
focused panel check on the release candidate confirmed the category logo,
retention of On/Off icons and brightness control; it does not establish full
2.2.5 pre-release or macOS compatibility.
