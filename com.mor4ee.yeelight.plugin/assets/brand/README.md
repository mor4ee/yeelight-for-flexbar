# Yeelight category icon

The transparent PNG is derived from the avatar of the [Yeelight organization](https://github.com/Yeelight).
It is used as a functional category badge in FlexDesigner to identify compatible
Yeelight lights. This independent plugin is not an official Yeelight product.
The project retains the badge on the basis of the
[Yeelight forum reply about functional badge use](https://forum.yeelight.com/t/use-of-yeelight-symbols-and-icons/4140).
